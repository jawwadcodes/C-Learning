# C++ Learning Journey — Introduction to Programming

A record of my progress learning C++ as part of the **Introduction to Programming** course at **IBA Karachi**.

## About

This repository documents my journey through the fundamentals of C++ and programming as a whole — from basic syntax to more advanced concepts covered in the course. It's both a study log and a place to keep the code I write along the way.

## Goals

- Build a solid foundation in C++ and core programming concepts
- Practice consistently and track progress over the semester
- Use these fundamentals as a stepping stone toward web/app development skills for a portfolio
